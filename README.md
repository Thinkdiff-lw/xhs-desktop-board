# 创作看板 · 小红书桌面数据

把最近发布的小红书文章放在桌面上，随时查看标题、浏览／阅读指标、评论和收藏。

看板采用深色半透明卡片，配合小字号、细线图标和少量红色点缀；也可切换到无整块背景的透明主题。日常桌面界面使用原生窗口，浏览器仅在登录和同步时按需启动。

> 独立的第三方工具，与小红书官方无隶属关系。需要在应用打开的官方创作后台中登录自己的账号。后台页面发生变化时，可能需要更新适配器。

## 下载与安装

从 [Releases](https://github.com/Thinkdiff-lw/xhs-desktop-board/releases) 下载对应系统的 ZIP；GitHub 的 **Source code** 是源码，不能直接双击运行。

| 系统 | 安装包 | 要求 |
| --- | --- | --- |
| Windows | `XhsBoard-Windows-x64-v1.0.0.zip` | Windows 10/11 x64、.NET Framework 4.8、WebView2 Runtime |
| macOS Beta | `XhsBoard-macOS-Universal-v1.0.0-Beta.zip` | macOS 13+，Apple Silicon 或 Intel |

Windows：完整解压到有写入权限的文件夹，双击 `XhsBoard.exe`。Mac：解压后把 `XhsBoard.app` 拖到「应用程序」，再打开。Mac 包使用临时签名，尚未经过 Apple 公证，首次打开可能需要在系统设置中允许。

初次启动后，从 Windows 托盘或 Mac 菜单栏选择「打开创作后台 / 重新登录」，完成官方页面登录。Mac Beta 尚未完成真实账号登录和桌面交互的实机验收，详见 [Mac 说明](docs/macOS.md)。

## 可以做什么

- 默认显示最近 5 篇已发布文章，可设置 1–50 篇；按发布时间排序，忽略旧文章的置顶顺序。
- 每篇展示标题及三项累计指标；缺失数据为 `—`，真实零值为 `0`。浏览量／阅读量沿用后台实际口径，不能理解为去重人数。
- 启动后同步，每 15 分钟自动更新；也支持手动刷新，避免同时运行多个采集进程。
- 拖动顶部移动，拖动窗口边缘调整大小；内容随宽度改变排列，放不下时使用细滚动条。
- 深色玻璃、透明两种主题；位置和大小预设、置顶、鼠标穿透、隐藏与恢复。
- 开机启动开关，默认关闭。Windows 不显示在任务栏及 Alt+Tab；Mac 常驻菜单栏，不显示 Dock 图标。
- 断网和同步失败保留最后成功的数据；登录失效或需要验证时暂停自动同步。

第一版展示当前累计数据，不含增长曲线、多账号、自动发文、评论回复或跨账号数据查询。

## 工作方式

Windows 桌面使用 WPF，采集进程使用 Python、pywebview 和 WebView2。Mac 桌面使用 Swift / AppKit，采集进程使用系统 WebKit。同步时打开官方创作后台，读取页面正常加载的已发布文章列表响应，不导出浏览器 Cookie，不计算请求签名，不用模拟数据冒充真实数据。

登录会话与日常 Chrome、Edge、Safari 独立。关闭日常浏览器不影响程序自己的会话；退出看板后停止同步。休眠期间不能定时刷新，唤醒后可点击刷新。

## 验证与限制

Windows 核心测试检查缺失值与零值、排序、分页、缓存和同步进程生命周期；原生窗口另提供独立自检。Mac 构建会生成通用二进制，并在 Apple Silicon、Intel 的 CI 环境执行核心自检。自动检查不能证明 Mac 真实后台登录、隐藏窗口加载、鼠标拖动、多屏及系统缩放已经通过实机验收；Mac 第一版因此标为 Beta。

应用没有自动更新器。升级时先退出程序，再替换程序文件，保留本地数据。反馈问题时请只提供系统版本、软件版本、状态文字和脱敏截图，不上传登录数据。
