# 开发与构建

## 目录

| 位置 | 职责 |
| --- | --- |
| `native_card/Program.cs` | Windows WPF 卡片、设置、托盘和采集调度 |
| `collector_worker.py` | 独立、按需启动的 Windows 浏览器采集进程 |
| `collector.py`、`xhs_adapter.py` | 响应观察、分页和字段映射 |
| `storage.py` | 本地设置与快照保存 |
| `app.py`、`web/`、`native.py`、`remote_session.py` | 保留的 Python 卡片实现，不作为原生桌面发布入口 |
| `macos/Core.swift` | Mac 数据模型、映射、排序、存储、核心自检 |
| `macos/Collector.swift` | WebKit 官方页面与受限响应观察 |
| `macos/Board.swift` | AppKit 卡片、设置、菜单栏与同步调度 |
| `tools/package_*.py` | 明确文件清单的干净发布包 |
| `.github/workflows/build.yml` | Windows、Apple Silicon 与 Intel 构建检查 |

## Windows

需要 Windows x64、Python 3.13、.NET Framework 4.8 编译器与 WPF 引用。普通用户直接下载 EXE，无须开发环境。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\build-native.ps1 -Python '.venv\Scripts\python.exe'
```

输出写入新的 `dist/native-时间-随机标识/`，保留旧目录。部署到源码根目录可加 `-Deploy`，先从托盘退出当前运行的应用。`build.ps1` 是安装依赖并部署的一键入口。

在指定的构建文件夹生成分享包：

```powershell
.\.venv\Scripts\python.exe tools/package_windows.py --binaries 'dist/你的构建目录' --output 'release/XhsBoard-Windows-x64-v1.0.0.zip'
```

打包器只选择两个 EXE、图标、启动脚本和通用说明；输出路径必须是新文件，防止静默覆盖已有 ZIP。

原生卡片支持 `--data-dir <独立目录>`、`--no-sync` 与 `--self-test`。自检在独立目录运行，检查布局及设置生命周期并输出自检文件；不要把真实浏览器资料用于 CI。测试中的合成文章只用于自检，不作为真实同步失败时的替代数据。

## macOS

需要 macOS 与 Xcode Command Line Tools。不能在普通 Windows 环境编译 AppKit 应用。

```bash
bash macos/build.sh
```

脚本编译 Swift 5 模式、最低 macOS 13，生成 `arm64`、`x86_64` 后合并；构建 `.app`，生成图标，进行临时签名、核心自检和 ZIP 清单检查。输出在新建的 `dist/macos-时间-UUID/`，不删除旧构建。

```bash
"dist/你的构建目录/XhsBoard.app/Contents/MacOS/XhsBoard" --self-test
```

`--collector` 是内部采集入口，通过运行 ID 隔离状态；每次只执行一次同步，完成或失败后退出。主卡片每 15 分钟创建一次采集进程，验证／登录状态暂停自动尝试。

## 数据口径与适配

观察官方页面正常请求的已发布标签 `tab=1` 列表响应。当前映射使用 `id`、`display_title`、`time`、`view_count`、`comments_count`、`collected_count`；阅读指标标签跟随页面。字段缺失保留为缺失，格式不明确不强行转换。

分页过程中排除定时／待审核文章，文章 ID 去重，按发布时间排序；置顶旧文章不改变「最近」含义。遇到结构变化、分页未前进或存储失败，报告失败并保留成功快照。

登录页面与本地界面隔离。不要为解决后台变化而添加 Cookie 导出、任意文件桥接或请求签名逻辑。

## 发布与验收

CI 编译和核心自检用于发现代码与包结构错误。真实账号数据一致性、隐藏窗口同步、多屏、缩放、穿透与登录项仍需实机验证。

公开前检查源码和 ZIP 清单；禁止包含 `data`、缓存、日志、凭据或个人截图。仓库忽略这些目录；提交仍应使用明确文件清单。构建脚本不包含批量删除行为。
