# 创作看板：安装与使用说明

## 1. 软件简介

创作看板是一款独立的桌面小工具，用来查看自己最近发布的小红书文章。卡片显示文章标题、后台提供的浏览／阅读指标、评论数、收藏数，以及同步状态和最后成功更新时间。

适合希望在写作、剪辑或日常工作时快速看一眼数据的创作者。默认 380 × 520，展示 5 篇；可按自己的桌面布局调整位置、大小、主题和显示数量。

这款工具需要在官方创作后台登录自己的账号。它只显示后台已经提供的数据，不生成估算阅读人数，不自动发布或回复。它是第三方项目，并非小红书官方软件。

## 2. 选择安装包

在项目的 GitHub「Releases」页下载对应系统的 ZIP，并可使用同页的 `.sha256` 文件核对完整性。

| 下载文件 | 用途 |
| --- | --- |
| `XhsBoard-Windows-x64-v1.0.0.zip` | Windows 10/11 64 位可运行版本 |
| `XhsBoard-macOS-Universal-v1.0.0-Beta.zip` | macOS 13 及以上，支持 Apple Silicon 与 Intel，Beta |
| Source code | 开发者源码；不是安装程序 |

Mac 的临时签名、系统首次放行和实机验收范围，请先阅读包内「macOS说明.md」或仓库的 Mac 说明。

## 3. Windows 安装

1. 下载后右键 ZIP，选择「全部解压」。不要直接在压缩包预览窗口里运行 EXE。
2. 把软件放在普通、可写入的文件夹。不要放在 Windows 系统目录或需要管理员权限才能写入的目录。
3. 保持 `XhsBoard.exe`、`XhsCollector.exe`、`icon.ico` 在同一个文件夹。`启动看板.bat` 是可选的启动入口。
4. 双击 `XhsBoard.exe`。程序会显示桌面卡片，并在任务栏右下角的系统托盘中出现图标；若看不到，展开托盘隐藏图标。
5. 从托盘菜单打开创作后台并登录。软件会在同一文件夹自动建立自己的 `data` 目录，首次安装包不附带任何账号数据。

系统需要 .NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。若提示缺少组件，请使用微软的官方安装程序，安装后重新启动软件。通常不需要以管理员身份运行。

官方组件地址：

- [.NET Framework 4.8](https://dotnet.microsoft.com/download/dotnet-framework/net48)
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)

Windows 版不是安装向导，解压后即可使用；软件没有自动更新器。

## 4. macOS 安装

1. 解压 Mac ZIP，把 `XhsBoard.app` 拖入「应用程序」。不要在下载目录中直接设置开机启动。
2. 双击应用。如果系统因未公证而拦截，确认文件来自本项目发布页，再按「macOS说明.md」中的系统流程允许打开。
3. 菜单栏出现图表图标，桌面显示卡片。应用没有 Dock 图标。
4. 从菜单栏图标选择「打开后台 / 重新登录」，在官方页面完成登录。

Mac 版使用系统 WebKit，用户不用安装 Python 或 WebView2。第一版为 Beta；实际账号登录、隐藏页面同步和桌面交互仍需在真实 Mac 上验收。

## 5. 首次登录与同步

1. 打开系统托盘／菜单栏菜单，选择「打开创作后台 / 重新登录」（Mac 为「打开后台 / 重新登录」）。
2. 在软件自己的「小红书创作后台 · 登录与同步」窗口按官方流程登录。扫码、短信和安全验证都在官方页面中完成。
3. 登录后等待已发布文章列表加载，程序读取正常加载的数据。不要把密码、短信验证码或 Cookie 发给其他人。
4. 看板出现文章标题和三项指标；底部状态变为「已同步」，更新时间变化。
5. Windows 手动打开的后台会保持可见，完成后可关闭后台窗口以释放浏览器内存。Mac 在本次同步完成后关闭采集窗口。

日常 Chrome／Edge／Safari 已登录，不代表这个软件也已登录。软件保存自己的本地会话；退出日常浏览器不影响后续更新。登录有效期由官方后台决定，不能保证永久有效。

第一次没有文章时，请区分「账号确实没有已发布文章」与「尚未同步／需要登录」。只有成功的后台响应才会更新看板；失败时不会填入演示文章。

## 6. 看板如何读

| 显示内容 | 含义 |
| --- | --- |
| 标题 | 已发布文章的标题，最多两行；鼠标悬停查看完整标题 |
| 浏览量／阅读量／观看量 | 沿用后台的实际标签；不是工具推算的去重阅读人数 |
| 评论、收藏 | 当前后台提供的累计数值 |
| `0` | 官方响应提供了真实零值 |
| `—` | 字段缺失、数值不可可靠解析，不能当成零 |
| 更新时间 | 最后一次成功获取并保存数据的时间，不是最后一次尝试时间 |

最近文章按发布时间从新到旧排列。主页置顶的旧文章不会自动排到第一位。待审核、草稿和定时发布文章不计入已发布文章。实际文章不足设置数量时，显示已有文章。

看板展示累计数据，后台统计延迟会反映在卡片上。自动同步周期为 15 分钟，不是每秒实时刷新。点击顶部刷新可立即尝试更新；不要连续点刷新来绕过后台验证或访问限制。

## 7. 移动、缩放与滚动

- **移动**：在顶部没有按钮的空白位置按住鼠标拖动，向任意方向移动。
- **缩放**：拖动窗口四周边缘或角落。最小尺寸约 320 × 260；默认 380 × 520。
- **自适应**：较宽时标题与数据更倾向于横向排列；较窄时数据放在标题下方。
- **滚动**：文章区域放不下时用鼠标滚轮，或拖动右侧的细滚动条。滚动条采用主题配色／系统覆盖式样式。
- **保存**：移动和缩放结果自动保存在本机，下次打开恢复。
- **多屏**：断开外接屏后，窗口会尝试回到可见屏幕；也可从设置选择角落或居中恢复。

打开鼠标穿透后，卡片不会响应点击、拖动或滚动，必须先从托盘／菜单栏关闭穿透。

## 8. 设置说明

点击顶部设置图标，修改后点击「保存设置」。点击「取消」不会应用当前修改。

| 设置 | 选项与效果 |
| --- | --- |
| 主题 | 「深色」为半透明玻璃卡片；「透明」取消整块背景，文字保留静态阴影 |
| 显示篇数 | 1–50 篇，默认 5；增加数量后可能需要再次同步 |
| 卡片位置 | 当前位置、四个角、居中；基于当前屏幕可用区域 |
| 卡片大小 | 当前尺寸、紧凑 320 × 360、中等 380 × 520、大号 520 × 700、宽幅 800 × 520 |
| 始终置顶 | 让看板位于普通窗口之上；不保证覆盖所有独占全屏程序 |
| 鼠标穿透 | 鼠标操作传给背后的窗口；通过托盘／菜单栏取消 |
| 开机启动 | 默认关闭；Windows 在当前用户登录时启动，Mac 使用系统登录项 |

Windows 的置顶、穿透、开机启动在「更多设置」中；Mac Beta 使用原生深色设置窗口，相关开关直接显示。系统样式控件和菜单会有平台差异。

选择「当前位置／当前尺寸」可以保留手动拖动结果。尺寸预设在小屏幕上会尽量适应可用区域；超出内容高度则滚动查看。

## 9. 隐藏、恢复、退出

| 操作 | Windows | macOS |
| --- | --- | --- |
| 隐藏 | 卡片 × 或托盘菜单 | 卡片 × 或菜单栏菜单 |
| 恢复 | 双击托盘图标／「显示桌面看板」 | 菜单栏「显示看板」 |
| 设置 | 顶部设置图标／托盘菜单 | 顶部设置图标／菜单栏菜单 |
| 退出 | 托盘菜单「退出」 | 菜单栏菜单「退出」 |

隐藏保留后台运行；退出停止后续同步。Windows 重复启动 EXE 会唤回已有实例。Mac 从 Finder 重复打开同一个应用会恢复卡片；不要同时启动不同副本或直接重复执行包内二进制。

## 10. 同步状态与故障处理

| 现象 | 处理 |
| --- | --- |
| 正在同步 | 等待一次采集结束；避免同时打开多个软件副本 |
| 需要登录 | 从托盘／菜单栏打开官方后台，重新登录 |
| 需要验证 | 打开官方后台手动完成验证；自动同步此时暂停 |
| 连接超时／同步失败 | 检查网络及官方创作后台是否能正常打开，再手动刷新 |
| 标题和数字未改变 | 先确认「更新时间」是否变化；后台可能有统计延迟 |
| 看不到卡片 | 找到托盘／菜单栏图标，选择显示；必要时在设置中选居中 |
| 卡片无法点击 | 从托盘／菜单栏关闭鼠标穿透 |
| 内存临时升高 | 正在登录或同步时浏览器多进程会启动；Windows 手动后台用完后关闭窗口 |
| 缺少 XhsCollector.exe | 重新完整解压发布包，保持两个 EXE 在同一文件夹 |
| 后台网页结构变化 | 更新软件；不要反复强制请求或导出 Cookie 作为替代 |

断网、超时或结构变化时保留上次成功数据与成功时间。登录失效／验证时暂停自动同步，完成重新登录后恢复。休眠时程序不能运行，唤醒后可以手动刷新；退出状态也不会更新。

程序不提供固定的内存占用承诺。原生卡片减少常驻浏览器开销，但同步仍需要加载官方后台；操作系统、页面内容和运行时版本都会影响内存。

## 11. 更新与数据迁移

**Windows 更新：** 从托盘退出旧版，解压新版，把新版程序文件放到原目录；保留原有 `data` 目录。不要用下载的空目录覆盖自己的数据。移到新目录时，同步搬移自己的 `data`，重新检查开机启动开关。

**Mac 更新：** 从菜单栏退出应用，在「应用程序」中替换为新版。设置和文章快照保存在当前用户的 Application Support 中；WebKit 登录会话由系统管理。若登录失效，请重新登录，不建议跨系统或跨账号复制浏览器数据。

Windows 和 Mac 的登录会话、设置和窗口坐标不能直接通用。

## 12. 卸载、安全分享与反馈

先关闭开机启动，再从托盘／菜单栏退出。Windows 可手动移除程序文件夹，Mac 可手动移除应用。若要清除本地账号数据，请参照隐私说明，确认备份和路径后自己处理；应用和构建脚本不会批量清理文件。

**分享给其他人时，直接转发官方发布包或发布页链接。不要把使用后的软件目录重新压缩发送。** 使用后的 `data`、WebKit 存储、日志、真实文章截图都可能含个人信息。每位使用者必须登录自己的账号。

提交问题时，提供系统版本、软件版本和底部状态文字即可。日志、截图请先脱敏；不需要提供手机号、验证码、密码、账号 Cookie 或完整数据目录。
