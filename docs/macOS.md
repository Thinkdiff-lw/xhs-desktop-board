# macOS Beta 说明

## 系统与下载

支持 macOS 13 及以上，安装包内是同时包含 `arm64` 和 `x86_64` 的通用应用。Apple Silicon 和 Intel 用户下载同一份 Mac ZIP。

Mac 版使用原生 Swift / AppKit 绘制卡片，系统 WebKit 执行登录和同步，不依赖 WebView2，也不要求用户安装 Python。

## 安装与首次打开

1. 从本项目 GitHub Releases 下载 `XhsBoard-macOS-Universal-v1.0.0-Beta.zip`。
2. 解压，把 `XhsBoard.app` 拖入「应用程序」，双击打开。
3. 当前包采用临时签名，**没有 Apple Developer ID 签名和公证**。如果系统拦截，先确认下载来源；按照 macOS 当前提示，在「系统设置 → 隐私与安全性」中允许打开，再确认系统弹窗。不同系统版本的按钮文字可能不同。
4. 找到菜单栏图表图标，选择「打开后台 / 重新登录」，在软件打开的官方创作后台中完成登录。
5. 一次同步完成后，采集窗口会关闭。桌面卡片、菜单栏仍然运行。

不需要关闭整个系统的安全检查，也不建议执行全局禁用 Gatekeeper 的命令。签名校验只能确认包内签名结构完整，不能代替公证或真实设备功能验收。

## 日常操作

顶部空白处拖动卡片，窗口边缘调整大小；文章区域支持滚轮和覆盖式滚动条。顶部按钮依次提供刷新、置顶、设置和隐藏。

菜单栏提供显示／隐藏、刷新、重新登录、玻璃／透明主题、置顶、鼠标穿透、设置和退出。开启鼠标穿透后，从菜单栏关闭。应用不显示 Dock 图标。

设置提供显示 1–50 篇、位置和尺寸预设，以及登录时启动。启动开关默认关闭，使用 macOS 的 `SMAppService.mainApp`；系统可能要求确认登录项，开关的有效状态以系统设置中的「登录项」为准。移动应用后请重新确认登录项。

## 数据保存

设置、最后成功的文章快照和本次同步状态保存在：

```text
~/Library/Application Support/XhsDesktopBoard/
```

WebKit 的持久化登录会话由应用默认网站数据存储管理，与 Safari 的日常登录状态独立。具体网站数据路径由系统管理，不保证全部保存在上面的目录中。不要公开上传 Application Support 数据或应用的 WebKit 存储。

## 已自动检查与待实机验收

构建流程在 Mac 上编译两种架构，合并通用二进制，检查 Info.plist、临时签名和 ZIP 内容，并在两种架构的 CI 机器执行核心自检。检查内容包括缺失／零值、发布时间、官方域名、已发布标签、去重排序、认证错误和设置边界。

以下项目需要真实 Mac 与使用者自己的账号验收，**不能由自动测试证明**：

- 官方页面登录、扫码／短信和验证流程是否正常。
- 隐藏的 WebKit 窗口是否持续触发页面数据加载，关闭 Safari 后是否仍可完成下一次同步。
- 真实后台的标题、发布时间和三项指标是否一致，分页能否覆盖设置的文章数量。
- 窗口四边／四角缩放、拖动、主题切换、穿透和菜单栏恢复。
- 外接显示器移除、缩放、Spaces、全屏应用和登录项启动行为。

因此第一版标为 **Beta**。如果官方页面未返回可用响应，程序显示失败并保留上次数据，不会填入演示数值，也不能视为已经实现真实接入验收。

问题反馈请只附系统版本、芯片类型、状态文字和脱敏截图。

参考：[Apple 网站数据存储](https://developer.apple.com/documentation/webkit/wkwebsitedatastore)、[Apple 登录项接口](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp)。
