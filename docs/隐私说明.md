# 隐私与分享说明

## 发布包里有什么

公开源码与安装包包含程序、通用图标、公开文档及合成测试数据。发布脚本按固定文件清单打包，不遍历使用中的软件目录。

发布包不包含已登录账号、真实文章标题或指标、浏览器个人资料、缓存、运行日志、桌面截图、联系方式或开发者的本机目录。提交作者使用项目名称。

公开项目托管在 GitHub。GitHub 页面会按平台规则显示仓库所属账号及操作记录；这与程序是否包含个人账号数据是两回事。

## 使用时会保存什么

- 本地设置：主题、窗口位置和大小、显示篇数、置顶、穿透等。
- 文章快照：最近一次成功同步的文章 ID、标题、发布时间及三项指标。
- 登录会话：官方后台登录状态，由应用自己的浏览器数据存储保存。
- 同步状态；Windows 另有采集／错误日志，错误堆栈可能包含运行环境信息。

Windows 数据默认位于软件文件夹的 `data` 中。Mac 的设置和快照位于 `~/Library/Application Support/XhsDesktopBoard/`；WebKit 网站数据另由系统管理。

本应用没有遥测、云端账号同步或上传文章数据的接口。网络访问来自官方创作后台及其页面正常加载的资源；第三方平台本身的数据处理规则以其页面与协议为准。

## 登录窗口的边界

只在官方创作后台页面登录，不要求使用者提供 Cookie 文件，不执行请求签名或绕过验证。读取的是页面正常加载的已发布文章列表响应；程序不把完整网络响应、Cookie 或密码写入文章快照。

Windows 登录页面不注册 Python 设置／文件控制接口。Mac 登录页面只注册受限的列表响应接收器，检查主框架、官方 HTTPS 域名、已发布标签和预期分页，不提供任意文件、命令或设置调用接口。

## 如何分享

推荐分享 GitHub 发布页链接或原始发布 ZIP。每个人安装后登录自己的账号。

不要把使用后的完整软件目录、`data`、WebKit 存储、日志或真实后台截图发给别人。分享问题截图前，遮盖头像、账号名、手机号、文章标题以及不希望公开的数据。

如果账号会话疑似泄露，请使用官方账号安全功能退出相关设备／会话，重新登录；仅移除桌面应用并不代表官方账号已注销。

## 清除数据

关闭开机启动并退出应用，确认路径与备份后，由使用者手动清理自己的数据。项目构建和发布脚本不批量删除文件，也不主动删除个人登录存储。
